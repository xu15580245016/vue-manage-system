# Bug修复验证说明文档

## 修复概述

本次修复了Vue3后台管理系统中的4个Bug，所有修复均采用最小改动原则，不破坏原有功能。

---

## Bug1: 打开表单菜单时控制台有警告

### 问题原因
**警告来源有两处：**

1. **复选框/单选框冲突**：`el-checkbox` 和 `el-radio` 同时设置了 `label` 和 `value` 属性导致冲突。在Element Plus中，`label` 属性本身就既是显示文本也是选项值。

2. **滑块prop重复**：数字输入框和滑块都设置了 `prop="num"`

### 修复方案
1. **复选框和单选框**：移除多余的 `value` 属性，只保留 `label`
2. **滑块联动**：移除表单项的 `prop` 属性，保留 `v-model="form.num"` 实现联动

### 修改文件
- `src/views/element/form.vue`

### 验证方法
1. 启动项目后，点击左侧菜单「组件」→「表单」
2. 打开浏览器控制台（F12）
3. 确认**没有任何**Vue警告信息
4. 修改数字框数值，滑块会同步变化；拖动滑块，数字框也会同步变化（联动功能正常）
5. 复选框和单选框功能正常

## Bug2: 选择主题颜色后，刷新页面有时会变回初始颜色

### 问题原因
在 `src/main.ts` 中没有调用主题Store的 `initTheme()` 方法，导致页面刷新后没有从localStorage读取并恢复已保存的主题颜色。

### 修复方案
1. 在main.ts中引入 `useThemeStore`
2. 在Pinia初始化后调用 `theme.initTheme()` 方法

### 修改文件
- `src/main.ts`

### 验证方法
1. 登录系统后，点击左侧菜单「主题」
2. 选择一个非默认的主题颜色（如红色、绿色等）
3. 刷新页面（F5）
4. 确认主题颜色没有恢复为初始颜色，保持用户选择的颜色

## Bug3: 表格的序号不对

### 问题原因
1. **初始公式错误**：`index + 1 + currentPage.value * pageSize.value`，导致第1页序号从11开始
2. **响应式问题**：使用 `toRefs` 解构的值有更新延迟问题
3. **Template渲染问题**：
   - v-for的key设置不正确：index列的prop是undefined，导致key重复警告
   - 同一个插槽 `#default` 使用两次v-if，导致template条件渲染警告

### 修复方案
1. 修正序号计算公式并直接访问props：`(props.currentPage - 1) * props.pageSize + index + 1`
2. 修复v-for的key：`:key="item.type || item.prop"`
3. 修复template条件渲染：把v-if放在插槽内部用span判断

### 修改文件
- `src/components/table-custom.vue`

### 验证方法
1. 点击左侧菜单「表格」→「基础表格」
2. 确认第1页序号从1开始，依次为1, 2, 3...10
3. 切换到第2页
4. 确认第2页序号从11开始，依次为11, 12, 13...20

## Bug4: 普通用户登录时控制台报错，首页订单动态和品类分布图表不显示

### 问题原因
在 `src/store/permiss.ts` 中，权限获取逻辑有缺陷：
```typescript
// 错误代码：当username为null或非admin用户时可能返回undefined
key: (username === 'admin' ? defaultList.admin : defaultList[username as string]) as string[]
```

导致的问题：
1. localStorage中没有 `vuems_name` 时，username为null，访问 `defaultList['null']` 返回undefined
2. `permiss.key.includes()` 调用时因为key是undefined报错
3. 权限验证失败导致页面异常，图表无法正常渲染

### 修复方案
优化权限获取逻辑，添加回退机制：
```typescript
key: defaultList[username as keyof ObjectList] || defaultList.user
```

当username不是有效的键名时，默认使用user权限。

### 修改文件
- `src/store/permiss.ts`

### 验证方法
1. 清除浏览器localStorage（F12 → Application → Local Storage → 清除）
2. 使用普通用户账号登录（用户名：user，密码可查看login.vue）
3. 打开浏览器控制台
4. 确认没有权限相关的报错信息
5. 确认首页「订单动态」和「品类分布」图表正常显示
