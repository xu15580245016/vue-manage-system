### Bug 1: 表单菜单控制台警告

**问题描述**: 打开表单菜单时控制台出现警告

**根本原因**: Element Plus 2.x 版本中，`el-radio` 和 `el-checkbox` 组件的 `label` 属性已被废弃，应该使用 `value` 属性来指定选项值，而选项文本应该放在标签内容中。

**修复文件**: [src/views/element/form.vue](file:///g:/git仓库/20260410/大屏看板1/kimi-2.5/vue-manage-system/src/views/element/form.vue)

**修复内容**:
```vue
<!-- el-radio 修复前 -->
<el-radio label="小明" value="小明"></el-radio>
<el-radio label="小红" value="小红"></el-radio>
<el-radio label="小白" value="小白"></el-radio>

<!-- el-radio 修复后 -->
<el-radio value="小明">小明</el-radio>
<el-radio value="小红">小红</el-radio>
<el-radio value="小白">小白</el-radio>

<!-- el-checkbox 修复前 -->
<el-checkbox label="小明" value="小明" name="type"></el-checkbox>
<el-checkbox label="小红" value="小红" name="type"></el-checkbox>
<el-checkbox label="小白" value="小白" name="type"></el-checkbox>

<!-- el-checkbox 修复后 -->
<el-checkbox value="小明" name="type">小明</el-checkbox>
<el-checkbox value="小红" name="type">小红</el-checkbox>
<el-checkbox value="小白" name="type">小白</el-checkbox>
```

**验证方法**:
1. 登录系统
2. 导航到 "Element" -> "表单" 菜单
3. 打开浏览器开发者工具 (F12)
4. 确认控制台没有关于 `el-radio` 和 `el-checkbox` 的警告信息

### Bug 2: 主题颜色刷新后变回初始颜色

**问题描述**: 选择了一个主题颜色，但刷新页面时，有时会变回初始颜色

**根本原因**: `themeStore` 中的 `initTheme()` 方法虽然在 store 中定义了，但在应用启动时（main.ts）没有被调用，导致 localStorage 中保存的主题颜色没有被正确加载。

**修复文件**: [src/main.ts](file:///g:/git仓库/20260410/大屏看板1/kimi-2.5/vue-manage-system/src/main.ts)

**修复内容**:
```typescript
// 添加导入
import { useThemeStore } from './store/theme';

// 在 app.mount('#app') 之前添加
const themeStore = useThemeStore();
themeStore.initTheme();
```

**验证方法**:
1. 登录系统
2. 导航到 "主题设置" 页面
3. 选择一个非默认的主题颜色（如"健康"主题 #1ABC9C）
4. 刷新页面 (F5)
5. 确认主题颜色保持为选择的颜色，而不是变回默认颜色

### Bug 3: 表格序号不对

**问题描述**: 表格的序号显示不正确

**根本原因**: 
1. `table-custom.vue` 组件中的 `getIndex` 方法计算公式错误。当前公式 `index + 1 + currentPage * pageSize` 会导致第2页的第1条数据显示序号为 21 而不是 11。
2. `basetable.vue` 没有传递 `pageSize` 属性给 `TableCustom` 组件，导致使用的是默认值。

**修复文件**: 
- [src/components/table-custom.vue](file:///g:/git仓库/20260410/大屏看板1/kimi-2.5/vue-manage-system/src/components/table-custom.vue)
- [src/views/table/basetable.vue](file:///g:/git仓库/20260410/大屏看板1/kimi-2.5/vue-manage-system/src/views/table/basetable.vue)

**修复内容**:
```typescript
// table-custom.vue - 修复前
const getIndex = (index: number) => {
    return index + 1 + currentPage.value * pageSize.value
}

// table-custom.vue - 修复后
const getIndex = (index: number) => {
    return index + 1 + (currentPage.value - 1) * pageSize.value
}
```

```vue
<!-- basetable.vue - 修复前 -->
<TableCustom :columns="columns" :tableData="tableData" :total="page.total" :viewFunc="handleView"
    :delFunc="handleDelete" :editFunc="handleEdit" :refresh="getData" :currentPage="page.index"
    :changePage="changePage">

<!-- basetable.vue - 修复后 -->
<TableCustom :columns="columns" :tableData="tableData" :total="page.total" :viewFunc="handleView"
    :delFunc="handleDelete" :editFunc="handleEdit" :refresh="getData" :currentPage="page.index"
    :changePage="changePage" :pageSize="page.size">
```

**计算公式说明**:
- 第1页第1条: `(1-1) * 10 + 0 + 1 = 1` ✓
- 第2页第1条: `(2-1) * 10 + 0 + 1 = 11` ✓
- 第3页第6条: `(3-1) * 10 + 5 + 1 = 26` ✓

**验证方法**:
1. 登录系统
2. 导航到 "基础表格" 页面
3. 查看第1页，确认序号从 1 开始
4. 点击第2页，确认序号从 11 开始（而不是 21）
5. 点击第3页，确认序号从 21 开始

### Bug 4: 普通用户登录时报错，首页图表不显示

**问题描述**: 普通用户登录时控制台报错，首页订单动态和品类分布图表不显示

**根本原因**: `permiss.ts` store 中，当用户不是 `admin` 时，`defaultList[username]` 可能返回 `undefined`（如果用户名不是预定义的 `user`），这会导致 `permiss.key` 为 `undefined`，后续代码调用 `includes` 方法时会报错。

**修复文件**: [src/store/permiss.ts](file:///g:/git仓库/20260410/大屏看板1/kimi-2.5/vue-manage-system/src/store/permiss.ts)

**修复内容**:
```typescript
// 修复前
key: (username === 'admin' ? defaultList.admin : defaultList[username as string]) as string[]

// 修复后
key: (username === 'admin' ? defaultList.admin : (defaultList[username as string] || defaultList.user)) as string[]
```

**验证方法**:
1. 退出登录（清除 localStorage 中的 `vuems_name`）
2. 使用非 admin 用户名登录（如 `test`、`user` 或任意用户名）
3. 确认控制台没有报错
4. 确认首页的 "订单动态" 和 "品类分布" 图表正常显示
